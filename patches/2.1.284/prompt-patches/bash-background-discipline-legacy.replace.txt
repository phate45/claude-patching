You can use the `run_in_background` parameter to run the command in the background. Only use this if you don't need the result immediately and are OK being notified when the command completes later. You do not need to check the output right away - you'll be notified when it finishes. You do not need to use '&' at the end of the command when using this parameter. Once backgrounded, don't poll or check on it \u2014 end your turn and wait for the exit notification, then read the output file it links. Don't pipe a big-output command through `| tail`; run it plain and read that output file after it exits.
